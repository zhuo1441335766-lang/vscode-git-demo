# 版本路线图

## 产品基线

V0.1 已可稳定交付（维护者确认）。后续重点为界面升级和功能新增，缺陷按实际反馈修复。版本范围按验收推进，暂不承诺日历交付日期。

| 版本 | 状态 | 主题 | 交付范围 | 验收出口 |
| --- | --- | --- | --- | --- |
| V0.1.0 | 现有产品基线，待 GitHub 发布归档 | 初版归档 | 当前功能清单、基线提交、启动说明 | 记录交付物、环境与已知限制 |
| V0.2.0 | 计划 | UI 样板升级 | 主框架、导航、统一样式、充电页样板 | 视觉确认、原操作回归、截图归档 |
| V0.3.0 | 候选 | UI 推广 | 将样板推广到仪表、车控和 QNX 页面 | 页面覆盖表和回归记录完成 |
| V0.4.0 | 候选 | 新增功能 | 从需求池选定常用场景或预设功能 | 明确范围、设备验证、操作说明 |
| V1.0.0 | 远期目标 | 完整交付 | 达成约定功能范围与兼容范围 | 发布包、使用文档、验收记录齐全 |

V0.1.x 用于维护现有交付版。新增需求先进入 Issue，经过评估才纳入版本；候选功能不等同于已承诺交付。

## 优先级

- P0：阻断当前交付或关键操作的问题。
- P1：当前迭代约定交付的 UI 和功能需求。
- P2：后续体验优化或候选功能。

每轮只安排一组可验收目标，避免同时全面改界面和重写业务。UI 与功能修改拆分 PR，按关联需求分别验收。
