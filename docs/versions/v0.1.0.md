- 车控：车辆信息、门窗及其他页面入口；各入口实际完成范围以交付清单为准。
- 调试辅助：版本查询、日志、截图、投屏/录屏、APK 安装和应用进程操作。
- QNX：串口相关控制、指示灯和底栏、截图。
